# ERPFY

A modern, multi-tenant Enterprise Resource Planning (ERP) platform designed for scalable business operations.

## Overview
ERPFY provides enterprise-grade management tools for businesses across diverse industries, featuring isolated company workspaces, granular role-based access control, real-time analytics, and modular business workflows.

## Key Features
- **Multi-Tenant Workspaces**: Independent environments for each organization with isolated data, custom roles, and specific regional configurations.
- **Enterprise Security**: Role-based access control (RBAC), multi-factor authentication (TOTP), session management, and immutable audit logs.
- **Dynamic Business Workflows**: Modular architecture supporting Sales, Inventory, Invoicing, Procurement, CRM, and Financial Reporting.
- **High Performance Architecture**: Built with Next.js, React 19, TypeScript, and Tailwind CSS with zero runtime bloat.

## Getting Started

### Prerequisites
- Node.js >= 22.13.0
- npm >= 10.0.0

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
